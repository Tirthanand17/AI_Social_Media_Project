SQLite workflow tools

Post database, scheduling, rescheduling, approval, and review tracking.

This frontend page is connected with the backend APIs available in FastAPI docs.

Back to main app Open API docs
Step 1

Save post

Use backend API POST /api/db/posts to save generated captions into SQLite.

{
  "caption": "AI automation test caption #AI",
  "platform": "Instagram",
  "hashtags": "#AI #Automation",
  "title": "AI Social Studio post",
  "content_type": "reel",
  "created_by": "editor_creator"
}
Step 2

Schedule post

Use backend API POST /api/db/schedule to schedule a saved post.

{
  "post_id": 1,
  "scheduled_date": "2026-06-20",
  "scheduled_time": "19:00",
  "username": "editor_creator"
}
Step 3

Reschedule post

Use backend API POST /api/db/reschedule to change an existing scheduled time.

{
  "post_id": 1,
  "new_date": "2026-06-21",
  "new_time": "20:00",
  "username": "editor_creator",
  "reason": "Better engagement slot"
}
Step 4

Review tracking

Use backend API POST /api/db/review to save content performance ratings into SQLite.

{
  "post_id": 1,
  "platform": "Instagram",
  "caption": "AI automation test caption #AI",
  "rating": 5,
  "notes": "Good hook and CTA",
  "created_by": "editor_creator"
}
